# 要件定義: rss-reader

## 概要

RSSフィードを購読・管理し、技術記事を自動収集する機能を yomimono に追加する。
現在の Chrome 拡張機能による手動収集に加え、RSSフィードからの自動収集チャネルを提供することで、
記事の取りこぼしを減らし、継続的な技術情報のインプットを支援する。

## 参考

- Dosen Issue #14: RSSリーダー機能構築
- 参考実装: https://github.com/babarot/oksskolten (AI-native RSS reader)

## 要件

### 1. フィード定義

購読する RSS フィード URL をコード内にハードコードで定義する。

#### 受け入れ基準

- 1.1: 購読対象のフィード URL リストがソースコード内の設定ファイル/定数として管理されている
- 1.2: 各フィード定義にはURL とタイトル（表示名）を含む
- 1.3: フィードの追加・削除はコード変更とデプロイで行う

### 2. 記事の自動取得

定義されたフィードから定期的に新着記事を取得し、bookmarks として保存する。

#### 受け入れ基準

- 2.1: Cloudflare Workers の Cron Triggers が実行されたとき、システムは全定義フィードの新着記事を取得する
- 2.2: システムが新着記事を検出したとき、システムはその記事を未読状態の bookmark として保存する
- 2.3: システムが既に保存済みの記事 URL を検出したとき、システムは重複保存をスキップする
- 2.4: システムがフィードの取得に失敗したとき、システムはエラーをログに記録し、他のフィードの取得を継続する
- 2.5: システムが記事を保存するとき、システムは記事のタイトル・URL・取得時タイムスタンプを bookmark に含める

### 3. 記事の表示統合

RSS フィードから取得された記事は、既存の bookmark と同じ一覧・管理画面で表示する。

#### 受け入れ基準

- 3.1: RSS フィードから取得された記事は、既存の bookmark と同じ未読/既読管理・お気に入り機能を利用できる
- 3.2: RSS 記事と Chrome 拡張から登録された記事は区別なく同一の一覧に表示される

### 4. データモデル

RSS フィードからの記事取得に必要なデータモデルの拡張を行う。

#### 受け入れ基準

- 4.1: `bookmarks` テーブルに feedId (nullable) カラムを追加し、RSS 経由の記事を識別できる
- 4.2: Drizzle ORM のマイグレーションで既存データに影響を与えずスキーマを変更できる

### 5. フィード管理用 Claude Code Skill

Claude Code のスキルとして、フィードの追加・削除・一覧確認を対話的に行えるようにする。

#### 受け入れ基準

- 5.1: `/rss-add` スキルで、フィード URL を指定して `config/feeds.ts` に新しいフィード定義を追加できる
- 5.2: スキル実行時、フィード URL の有効性を検証（fetch してパース可能か確認）してからコードに追記する
- 5.3: スキルはフィードのタイトルを RSS フィードから自動取得し、定義に含める
