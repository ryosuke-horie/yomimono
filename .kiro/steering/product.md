# Product Context

## 目的

yomimono は技術記事の読書管理ツール。
ブラウザで開いた記事を一括収集し、未読/既読/お気に入りで整理する。

## 解決する課題

エンジニアは日常的に大量の技術記事をタブに開くが、読みきれずに失われがちである。
yomimono はこの「読みたかったのに消えた」問題を、収集から消化までのワークフローで解決する。

## ユーザーワークフロー

1. 気になった技術記事を複数のブラウザタブに開く
2. Chrome 拡張機能で開いているタブのリンクとタイトルを一括収集し API へ送信
3. フロントエンドで未読記事の一覧を確認し、興味のあるものから読む
4. 読了した記事は既読にマーク。特に有益な記事はお気に入りに追加して後から見返す

## コア機能

- ブックマーク収集: Chrome 拡張機能による一括タブ収集
- 未読/既読管理: 記事の消化状況を追跡
- お気に入り: 重要記事の長期保存
- 一覧/閲覧: フロントエンドでの記事管理インターフェース

## 設計原則

- シンプルさ優先: 最小限の操作で記事を収集・管理できること
- 個人利用: 認証なしの単一ユーザー想定
- 軽量インフラ: Cloudflare Workers + D1 によるサーバーレス運用
